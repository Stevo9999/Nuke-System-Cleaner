Nuke-Uninstaller (Windows 10/11, 64-bit)

TO INSTALL:   double-click  Install-Nuke-Uninstaller.exe   (or Install.bat)
  A setup wizard opens: accept the terms, choose the install folder (default C:\Program Files\Nuke-Uninstaller), click Install.
  It adds a desktop and Start-menu shortcut and offers to start the program. Windows may ask for permission once.
  Nothing else needs to be downloaded: no Node.js, no npm, no Electron. To remove it later: Windows Settings > Apps > Installed apps > Nuke-Uninstaller.

NO INSTALL (run from anywhere, even a USB drive):  double-click  Nuke-Uninstaller-Portable.exe
  Fully standalone: it does not need the installer or any other file. The portable version has no administrator mode.

Windows may show "Windows protected your PC" because the programs are not code-signed: click More info, then Run anyway.
